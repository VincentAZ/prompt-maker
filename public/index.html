                  🔌 LM Studio

                  Offline only: the app refuses anything that isn't this computer or your local network. Start and stop LM Studio's server in Services above. Choose the Brain in the top bar. Image input needs a vision model marked 👁.

                  ☁️ Cloud Brains optional

                  Prompt Maker runs 100% offline. If a local model isn't good enough, add a cloud provider with your own API key: its models then show up in the Brain menu, marked ☁️. Whatever you write with a cloud Brain is sent to that provider, and Prompt Maker asks before you switch to one.

                    🎨 ComfyUI optional

                    Keeps ComfyUI's output folder clean: Prompt Maker keeps every render in your data folder, with its own name. It only deletes the exact file it just copied, and only when ComfyUI runs on this computer. Deleting from History always removes ComfyUI's copies of those renders too, so the folder matters even with this off.

                    Only needed if you want to render prompts into images and videos. Start ComfyUI in Services above (or as usual), then attach workflows to a model in the Models tab. Prompt Maker starts it the way it last saw it running, or with live previews on (--preview-method auto).

                    ✦ Assistant

                    The assistant (✦ Ask, in the top bar) always runs Prompt Maker for you, and can find folders and look at pictures anywhere on this computer.

                    Off by default. When it's on, the assistant can also do things outside Prompt Maker: run programs and commands, and open, read and write any file on your drives, without asking each time. Anything that would delete something, or replace a file, still asks you first. Only you can switch this on or off.
